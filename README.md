# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, product performance, and factors influencing buying decisions.

The objective is to transform raw customer shopping data into meaningful business insights using Excel, MySQL, Python, and Power BI.

## Business Objectives

- Understand customer purchasing behavior and spending patterns.
- Identify popular products and high-performing categories.
- Analyze customer demographics and subscription behavior.
- Evaluate discount and promotional code usage.
- Understand payment methods and shipping preferences.
- Build an interactive dashboard to support data-driven decisions.

## Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel | Data cleaning and preparation |
| MySQL 8.0 | Data exploration, cleaning, and SQL analysis |
| Python | Exploratory Data Analysis (EDA) |
| Power BI | Interactive dashboard and data visualization |

## Dataset Description

The dataset contains customer shopping information, including:

- Customer ID
- Age and Gender
- Item Purchased
- Product Category
- Purchase Amount (USD)
- Location
- Size and Color
- Season
- Review Rating
- Subscription Status
- Payment Method
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Preferred Payment Method
- Frequency of Purchases

## Project Workflow

### 1. Data Cleaning Using Excel
- Imported and explored the raw dataset.
- Checked data consistency and formatting.
- Prepared the dataset for further analysis.

### 2. SQL Analysis Using MySQL
- Performed data exploration and validation.
- Checked missing values and duplicate customer IDs.
- Created a cleaned dataset.
- Used aggregate functions, GROUP BY, CASE statements, CTEs, and window functions.
- Analyzed customer, product, discount, and purchasing patterns.

### 3. Exploratory Data Analysis Using Python
- Performed exploratory data analysis.
- Examined customer demographics and purchasing trends.
- Analyzed product preferences and spending behavior.
- Created visualizations to understand patterns in the dataset.

### 4. Power BI Dashboard
- Developed an interactive dashboard.
- Presented important business metrics and shopping trends.
- Used visualizations to explore customer and product performance.

## Key Business Questions

1. Which product categories generate the highest purchase amount?
2. Which products are purchased most frequently?
3. Which age groups contribute to shopping activity?
4. How does subscription status relate to purchasing behavior?
5. How do discounts and promotional codes influence purchases?
6. Which payment methods are most commonly used?
7. Which seasons have higher shopping activity?
8. Which locations contribute the highest purchase amount?
